# Personal Website

A single-file personal website (HTML + CSS) — no build step, no dependencies.

## Sections
- Hero introduction
- About
- Skills
- Projects (linked to GitHub repos)
- Contact / social links

## Customize
Open `index.html` and edit:
- Your name (search for "Noor-ul-Eman")
- The About paragraph and stats
- Skills list
- Projects list and links
- Social links in the footer (LinkedIn, GitHub, Email)

## Usage
Open `index.html` directly in a browser, or serve it locally:
```
python -m http.server 8000
```
Then visit `http://localhost:8000`.
